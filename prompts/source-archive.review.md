## 7. 出典の原本の照合
- fetch_page.py の出力の `原本の照合:` の行と `FETCH_FAILED` の続きは、次のとおりに扱う
  - `いまは読み直せない(…)。下の本文は…に読んだ原本。出典として使ってよい`: その本文を出典のページの本文として R1〜R5 で照合する。読み直せないことではブロックしない
  - `…の原本から内容が変わっている`: 下の本文(いまの版)で照合する。記事が `--- 変わったところ ---` の古い値(延長前の締切・訂正前の記載・追加前の出演者 など)を今の事実として書いていれば R4 でブロックする
  - `FETCH_FAILED` のあとに `…にはこのページの本文があった。いまは無い(取り下げ・移動の可能性)`: その url を sources に残している記事、参考に出る原本だけを根拠にした事実は R4 でブロックする。その url を sources から外したことは R3 にしない
- 本文の末尾の「※」で始まり「読んだ原本に基づきます」を含む段落は、コードが付けた断り書き。根拠 id が無いこと・日付の書き方を含めて指摘しない
