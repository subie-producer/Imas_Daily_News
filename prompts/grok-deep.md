## 2. 手順
1. 問いごとに X を検索し、答えになる原本の投稿を探す。見つからない問いはファイルに何も書かずに次へ
2. 見つけた投稿を、1投稿1項目でファイルへ書く(形は下の「3. 書き方」)。どの問いでも見つからなければ、ファイルには「見つからない」とだけ書く
3. 最後に「N件書きました」とだけ報告する

## 3. 書き方(1投稿1項目。この形のとおりに書く。後段のコードがこの形を読む)
```
### 番号
- url: https://x.com/<アカウント>/status/<ID>
- 問い: 答えた問いの番号
- 投稿者: 表示名 (@アカウント)
- 投稿日時: 投稿の日時
- 本文:
(投稿の本文を全文そのまま。要約しない・言い換えない。引用・返信なら、元の投稿の url と本文も)
- リンク:
  - 投稿に付いたリンクの url(1行に1つ。無ければ「- リンク: なし」)
```
- ファイルの頭に題や見出しを書かない。問いの文を写さない(番号だけを「- 問い:」に書く)

## 4. やらないこと
- リンク先のページを開かない・調べない。画像をダウンロードしない
- 問いに無いことを調べない。同じ意味の言い換えの検索をしない
