「THE IDOLM@STER CINDERELLA GIRLS Memory Pict.」第6弾の受注が8月27日から始まった。今回の登場アイドルは小日向美穂と依田芳乃。11月お届け分のテーマは「アニバーサリー」で、記念日を祝うドレス姿の2人を描きおろしイラストで表現している。

ラインナップには、アクリルスタンド、アクリルパネル、ブロマイド、オーロラ缶バッジの4点を収めた「公式メモリーピクトBOX」がある。季節ごとに異なるアイドルたちの輝きを詰めるシリーズで、今回も特設サイトを通じて案内されている。

公式ニュースは、今回の商品を「シンデレラガール総選挙2026」の投票権獲得対象としていることも告知した。商品の購入・決済はASOBI STOREへのログインが必要で、販売終了後に再販される場合があるほか、生産予定数や生産上の都合で注文終了や届け予定日が変更される場合がある。
