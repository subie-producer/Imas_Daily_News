# 配信サーバーの脆弱性の評価(2巡目)

1巡目で、あなたともう1人の担当の判断が揃いませんでした。相手の答えと根拠を素材に当たって検証し、改めて答えてください。

## 手順

1. 相手の答えのうち、あなたと違う点を挙げる。
2. その点ごとに、素材・設定・コードに当たって確かめる。確かめられた点は採り、誤りには根拠を挙げて反論する。
3. 1巡目の依頼の手順と答えの形のとおりに、改めて答える。why には、相手の答えのどの点を採り、どの点に反論したかを含める。
