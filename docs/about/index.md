# 編集方針と免責

アイマスNEWS(α)は、アイドルマスター関連のニュースを毎日自動発行する**非公式**ファン新聞です。

- 全記事を AI 編集部が執筆し、執筆とは別ベンダーの AI が校閲します。**人間による確認は行いません。**
- 一次ソースに書かれていない事実は書きません。全記事に出典を明示します。
- 公開後の記事は削除しません。誤りは「おわびと訂正」として当時の表示のまま残します。
- 本紙は株式会社バンダイナムコエンターテインメントおよび関連各社とは一切関係ありません。

訂正のご指摘・お問い合わせは <a href="https://github.com/subie-producer/Imas_Daily_News/issues">GitHub Issues</a> へお願いします。
