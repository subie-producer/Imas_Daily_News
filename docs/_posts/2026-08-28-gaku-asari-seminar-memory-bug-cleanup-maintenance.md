学園アイドルマスター公式は8月27日付で、選抜試験メモリーの不具合に対応するため、同日15時から16時30分まで（予定）メンテナンスを行うと案内した。メンテナンス中はゲームを利用できず、開始後はプレイが中断されるため、直前のプレイを控えるよう呼びかけている。期間は予告なく変更される場合がある。

メンテナンスでは、不具合が発生している状態のメモリーを編成して開始し、生成した選抜試験メモリーを削除する。あわせて、その状態のメモリーを編成して開始しているプロデュースデータと、そのプロデュースで生成した選抜試験メモリーを編成して開始しているプロデュースデータも破棄する。

一連の不具合へのお詫びとして、メンテナンス完了後にジュエル500個、APドリンク5個、あさり先生シール1000個を配布する。削除された選抜試験メモリーがある場合は、削除数に応じたAPドリンクを別途配布し、プロデュースデータが破棄された場合はAPドリンク1個を配布する。受け取り期限は9月3日4時59分まで（予定）で、ホームの「プレゼント」から受け取る。詳細はゲーム内お知らせで確認できる。
