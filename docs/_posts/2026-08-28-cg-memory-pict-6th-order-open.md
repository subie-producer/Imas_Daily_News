「THE IDOLM@STER CINDERELLA GIRLS Memory Pict.」第6弾の受注が、8月27日から始まった。描きおろしイラストを使ったシリーズで、今回は小日向美穂と依田芳乃が登場。11月お届けのテーマはアニバーサリーで、ドレスで着飾った2人を描く。公式ニュースにはSpecial PVと特設サイトも案内されている。

ラインナップの公式メモリーピクトBOXは、アクリルスタンド、アクリルパネル、ブロマイド、オーロラ缶バッジの4点を詰めた商品。公式ニュースによると、本商品はシンデレラガール総選挙2026の投票権獲得の対象となる。

公式Xの案内では、受注期間は2026年8月27日から9月13日まで。販売終了後に再販される場合があり、受注期間などのスケジュールは予告なく変更される場合がある。また、他のアイテムとあわせて注文した場合は、全アイテムがそろってから発送される。
