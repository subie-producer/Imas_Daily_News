アイドルマスター関連の定点観測で見つかった新着ページ(末尾。`### 番号. URL` ごとに1件)から、事実を抽出して JSON 配列で返します。
JSON 配列だけを出力し、ほかの文字は書きません。配列は新着ページごとに1要素で、全ページぶんを番号順に並べます。

## 1. 手順
- ページを開くときは `python3 scripts/fetch_page.py <url>` で読む(WebFetch は使えない)。出力は `--- 本文(要約なし) ---` の後ろを全部読む
- fetch_page.py は1回の Bash に1ページずつ、`python3 scripts/fetch_page.py <url>` の形だけで打つ(前に cd・ls を繋がない、括弧でまとめない、grep・sed へ流さない、ファイルへ書き出さない)。ほかの形は拒まれて読めない。拒まれたら、この形で打ち直す
- 本文が「取得できず」のページは、その URL を開いて読む
- まとめサイトのページは、ページ内の一次ソースの URL を開いて本文を読み、その URL を `url` にする

## 3. 出力の形
新着ページ1件につき1要素:
```
{"page": 番号, "status": "extracted|none|unreadable", "items": [候補]}
```
- extracted: 本文を読み、候補を1件以上抽出した。`items` に候補を入れる
- none: 本文を読んだが、アイマスの事実が無い。`items` は空配列
- unreadable: 本文を読めなかった(fetch_page.py の失敗・空のページ・別のページへの転送など)。`items` は空配列
