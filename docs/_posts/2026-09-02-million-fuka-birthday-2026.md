『豊川風花Birthdayセット2026』が登場した。プラチナガシャ10回チケット、風花の衣装「マイオンリーフィットネス」、Birthday Memory 2026、スタイルドロップ100個、ドアデコセット最上級「Invit@tion!」、いろどりパネル最上級「Invit@tion!」が付属する。

あわせて『豊川風花Birthdayガシャ』も開催。豊川風花のカードのみが登場し、1ステップ目には衣装「マイオンリーフィットネス」、Birthday Memory 2026、スタイルドロップ100個、ドアデコセット最上級「Invit@tion!」、いろどりパネル最上級「Invit@tion!」が付与される。
