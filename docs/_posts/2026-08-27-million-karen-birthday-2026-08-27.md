『アイドルマスター ミリオンライブ！ シアターデイズ』で、篠宮可憐の誕生日を祝う企画が展開されている。8月27日の誕生日に合わせ、「篠宮可憐Birthdayガシャ」が開催。可憐のカードのみが登場し、1ステップ目には衣装「マイオンリーフィットネス」、Birthday Memory 2026、スタイルドロップ100個、ドアデコセットといろどりパネルの最上級「Invit@tion!」が付く。

あわせて「篠宮可憐Birthdayセット2026」も登場した。プラチナガシャ10回チケットに、ガシャと同じ衣装やBirthday Memory 2026、スタイルドロップ100個、各種デコレーションアイテムが付属する。

劇場ではバースデーライブに合わせ、外観を可憐仕様にデコレーション。ホワイトボードには天空橋朋花、徳川まつり、我那覇響、田中琴葉、舞浜歩がメッセージを寄せている。ゲーム内の各所で、可憐の誕生日を祝う内容となっている。
