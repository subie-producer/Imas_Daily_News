8月29日は菊地真の誕生日。ミリシタでは「菊地真Birthdayガシャ」が開催され、真のカードのみが登場する。1ステップ目には、衣装「マイオンリーフィットネス」、Birthday Memory 2026、スタイルドロップ100個、ドアデコセット 最上級「Invit@tion!」、いろどりパネル 最上級「Invit@tion!」が付く。

あわせて「菊地真Birthdayセット2026」も登場した。プラチナガシャ10回チケットに加え、衣装「マイオンリーフィットネス」、Birthday Memory 2026、スタイルドロップ100個、ドアデコセット 最上級「Invit@tion!」、いろどりパネル 最上級「Invit@tion!」がセット内容となっている。

劇場外観は菊地真の誕生日仕様にデコレーションされ、ホワイトボードには雪歩、静香、ロコ、桃子、百合子からのメッセージが掲示されている。
