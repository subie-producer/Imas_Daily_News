学園アイドルマスター公式は、秦谷美鈴の思い出衣装を8月26日（水）11時から開催予定と案内している。対象となるのは、過去のストーリーイベント「生徒会 1 年組の日常」で登場した美鈴の「お気に入りの私服」。今回のイベントは常設で、いつでも遊べる。美鈴の印象的な私服を手に入れられる機会となる。
