ASOBI STOREは、「THE IDOLM@STER CINDERELLA GIRLS Memory Pict. November」のグッズを受注販売している。

「公式メモリーピクトBOX」は、アクリルスタンド、アクリルパネル、ブロマイド、オーロラ缶バッジの4点入りで、5,900円（税込）。単品では「公式オーロラ缶バッジ」が500円、「公式B2タペストリー」が5,000円、「公式キャラファイングラフ」が16,000円（いずれも税込）。

受注販売は2026年9月13日（日）までの予定で、商品は2026年11月下旬以降順次発送予定。
