9月26日はジュリアの誕生日。バースデーライブに合わせて劇場外観がジュリア特別仕様にデコレーションされ、ホワイトボードには音無先輩、美也、麗花、のり子、やよいからのメッセージが掲示されている。 <!-- F3 F4 F5 F6 F7 F8 F9 F10 -->

ミリシタでは「ジュリアBirthdayセット2026」が登場。プラチナガシャ10回チケット、衣装「マイオンリーフィットネス」、Birthday Memory 2026、スタイルドロップ100個、ドアデコセット「最上級：Invit@tion!」、いろどりパネル「最上級：Invit@tion!」が付属する。また、「ジュリアBirthdayガシャ」ではジュリアのカードのみが登場し、1ステップ目に同衣装、Birthday Memory 2026、スタイルドロップ100個、2種のデコアイテムが付く。アプリ内では「#ジュリア誕生祭2026」としてお祝いに行くリンクも案内されている。 <!-- F15 F16 F17 F18 F19 F20 F21 F26 F27 F28 F29 F30 F31 F32 F38 F40 F41 -->
